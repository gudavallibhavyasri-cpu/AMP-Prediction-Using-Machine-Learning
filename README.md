# Antimicrobial Peptide (AMP) Prediction Using Machine Learning

A machine-learning project for analysing peptide sequences and classifying them as AMP-like or non-AMP-like using sequence-derived physicochemical and compositional features.

The project combines biological sequence processing, feature engineering, machine-learning model development, model evaluation, and deployment through FastAPI and Streamlit.

## Project Overview

Antimicrobial peptides (AMPs) are important components of innate immunity and are being investigated for their potential applications in combating microbial infections.

This project explores whether machine-learning algorithms can distinguish known AMP sequences from artificially shuffled peptide sequences using sequence-based features.

The workflow includes:

- Collection and curation of public AMP sequence databases.
- Sequence cleaning and deduplication.
- Synthetic negative-control generation.
- Feature extraction using Biopython.
- Machine-learning model comparison and optimisation.
- Model evaluation using a held-out test set.
- Deployment through a FastAPI backend and Streamlit frontend.

## Data Sources

The project uses publicly available peptide information from:

- APD3 — Antimicrobial Peptide Database.
- DBAASP — Database of Antimicrobial Activity and Structure of Peptides.
- DRAMP — Data Repository of Antimicrobial Peptides.

The raw database files and processed datasets are not included in this repository. Users should obtain the data from the respective database providers and follow their access and redistribution conditions.

## Dataset Preparation

The curated master dataset contains:

| Dataset characteristic | Count |
|---|---:|
| Total source records | 18,084 |
| Eligible records | 15,909 |
| Unique eligible peptide sequences | 12,159 |
| Unique positive sequences | 12,159 |
| Synthetic negative sequences | 12,139 |
| Total training sequences | 24,298 |

Exact duplicate sequences across databases were consolidated while retaining source provenance.

Sequences were filtered according to eligibility criteria, including standard amino-acid composition and minimum sequence length.

### Synthetic Negative Controls

Negative controls were generated by shuffling the amino-acid order of positive peptide sequences.

This approach preserves the original amino-acid composition and sequence length while changing residue order.

**Important:** These shuffled sequences are artificial controls. They are not experimentally confirmed non-antimicrobial peptides. Therefore, the model's performance should be interpreted as its ability to distinguish database AMP sequences from this particular synthetic control set, not as validated biological AMP prediction performance.

## Feature Engineering

A total of **422 sequence-derived features** were extracted.

| Feature category | Number of features |
|---|---:|
| Amino Acid Composition (AAC) | 20 |
| Dipeptide Composition (DPC) | 400 |
| Average Hydrophobicity | 1 |
| Approximate Net Charge | 1 |
| **Total** | **422** |

Features include:

- Amino acid composition.
- Dipeptide composition.
- Average hydrophobicity using the Kyte–Doolittle scale.
- Approximate net charge based on positively and negatively charged residues.

The approximate net charge is a simplified residue-count feature, not a pH-dependent molecular charge calculation.

## Machine Learning Models

The following algorithms were evaluated:

1. Random Forest Classifier.
2. Logistic Regression.
3. Support Vector Machine (SVM).

Feature scaling was investigated for Logistic Regression and SVM.

Random Forest hyperparameters were further optimised using RandomizedSearchCV with StratifiedGroupKFold cross-validation.

The final selected model is an optimised Random Forest classifier.

## Model Evaluation

The final model was evaluated on a held-out test set.

| Metric | Result |
|---|---:|
| Accuracy | 0.8192 |
| Precision | 0.8965 |
| Recall | 0.7224 |
| F1-score | 0.8001 |
| ROC-AUC | **0.8979** |

### Confusion Matrix

| | Predicted Negative | Predicted Positive |
|---|---:|---:|
| Actual Negative | 2,179 | 199 |
| Actual Positive | 662 | 1,723 |

The test split was grouped by amino-acid composition to reduce leakage between sequences with identical composition.

However, this does not eliminate sequence-homology or similarity leakage. Independent validation using experimentally characterised positive and negative peptides is still required.

## Feature Importance

The optimised Random Forest model was analysed using built-in impurity-based feature importance.

The highest-ranked individual features included:

- Average Hydrophobicity
- AAC_K
- AAC_L
- AAC_I
- Approximate Net Charge
- AAC_G
- AAC_R
- DPC_KK

Feature importance indicates how the trained model uses features; it does not establish biological causation.

The summed importance of feature categories is also affected by the number of features in each category, particularly the 400 DPC features.

## Application Architecture

The project includes a FastAPI backend and Streamlit frontend.

**Workflow:**

1. User enters a peptide sequence.
2. Streamlit sends the sequence to the FastAPI endpoint.
3. The API validates the sequence.
4. The feature extraction module calculates 422 features.
5. The optimised Random Forest generates a classification and AMP-class score.
6. The result is returned and displayed in Streamlit.

## Limitations

- Synthetic shuffled sequences are used as negative controls rather than experimentally confirmed non-AMPs.
- The reported ROC-AUC measures discrimination between the constructed dataset classes.
- The composition-group split does not fully control for sequence similarity or homology.
- Independent external validation is required.
- Experimental antimicrobial activity, toxicity, and selectivity cannot be established through this computational model alone.
- The AMP-class score is not a calibrated probability of biological antimicrobial activity.
